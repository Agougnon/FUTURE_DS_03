Future Interns - Data Science and Analytics Track
Task 3: Marketing Funnel and  Conversion Performance Analysis

Project Overview
This repository contains the completed work for Task 3 of the Future Interns Data Science and Analytics internship program.
Objective:Analyze marketing funnel data to identify conversion drop-offs, evaluate funnel performance across stages, and formulate data-driven recommendations to optimize lead-to-customer conversion.

Tools and Technologies Used
Python(Pandas, NumPy for data aggregation and conversion metric calculations)
Seaborn and Matplotlib(for visualization of user volume per funnel stage)
VS Code (Development Environment)

 Key Insights and Findings
Funnel Progression & Drop-offs:
Homepage to Product Page: 50% of users drop off before viewing a specific product page (10,000 down to 5,000 users).
Product Page to Cart: A steep drop occurs as only 1,500 users proceed to add items to their cart.
Final Purchase Conversion:Only 225 users reach the final purchase stage, highlighting critical friction points in the checkout and payment process.

 Business Recommendations
1. Optimize Product Discovery: Improve homepage design and navigation recommendations to guide more users smoothly from the landing page to product details.
2. Reduce Cart Abandonment: Implement exit-intent pop-ups, streamlined checkout forms, or automated reminder emails for items left in carts to boost conversion rates in the final steps.

Repository Structure
1-"user_data.csv": The primary dataset containing user interactions across different funnel stages.
2-"funnel_analyse.py": The Python script used for data aggregation, conversion rate calculations, and graphical representation.
